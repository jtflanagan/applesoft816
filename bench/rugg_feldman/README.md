# Rugg/Feldman benchmarks (Kilobaud, June 1977)

BM1-BM8 as listed in Wikipedia's "Rugg/Feldman benchmarks" article, typed in
at the ] prompt by the profiler.  Published Applesoft times (Apple II, 1 MHz,
seconds, from PCW via that article): 1.3 8.5 16.0 17.8 19.1 28.6 44.8 55.5.
Those were stopwatch times; the profiler's are emulated cycles at 1.0205 MHz.
